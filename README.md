## 它能做什么

单文件、零依赖、纯本地运行的工具：

- **输入**：配置链接 / 粘贴 JSON / 上传文件（支持一次多份、一份内含多段）
- **解析**：自动提取链接（多通道竞跑）、容错解析（注释 / 控制字符 / 多段拼接）、
  自动补全相对路径、多源合并去重
- **结果**：多类条目分类展示 + 名称搜索（类 Ctrl+F，循环定位）
- **导出**：勾选需要的条目 → 自动补全依赖配置 → 导出前预检 → 下载

**核心能力**：多源合并时自动为每个条目补全它所属来源的依赖配置
（主配置只有一个全局槽位，逐条补全是唯一可行方案），条目可用率可从 ~64% 提到 ~99%。

数据不上传任何服务器，全部在浏览器本地完成。

## 设计原则（改动前先确认不违背）

1. **条目级依赖补全是核心机制** —— 合并多来源配置时的关键环节。
2. **单源跟随来源配置，多源才用选优 / 兜底** —— 实测出来的最稳策略。
3. **只做语法级判定，不做可达性猜测** —— 浏览器端无法可靠判活。
4. **工具保持中立** —— 不内置任何数据、不硬编码任何地址。
5. **导出前必须过审核** —— 提示文案要与实际行为一致。
6. **解析后默认不全选** —— 用户手动勾选后导出。
